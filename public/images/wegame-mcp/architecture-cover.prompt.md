# wxgame-mcp 架构封面生成提示词

## 生成模式

Codex 内置 ImageGen，用途分类：`infographic-diagram`

## 主提示词

为开源项目 `wxgame-mcp` 生成一张 16:9 横版的中文系统架构封面，清楚表现 AI Agent 如何通过 MCP 驱动微信小游戏开发者工具，并在 AppService 中完成自动化调试。

使用深墨黑至深蓝灰渐变背景、轻微网格和细发光线路。主体是五层横向数据流架构：

1. “AI 编程客户端”
2. “MCP 工具层 · 46 个工具”
3. “会话与开发者工具控制”
4. “AppService 运行时探针”
5. “微信小游戏”

主链路下方展示六个能力模块：“截图与交互”“日志与错误”“网络抓包与 Mock”“性能与内存”“PIXI 场景树”“广告与音频追踪”。

底部用三个标签突出“复用 IDE”“幂等注入”“零业务依赖”。

主标题：“微信小游戏 MCP 自动化调试架构”

副标题：“让 AI 直接观察、操作并诊断小游戏运行时”

风格为高级软件架构信息图，使用现代编辑器和开发者工具视觉语言。主标题左上，主体架构居中，所有中文标签在缩略图尺寸仍可读。以微信绿、青色和低饱和紫蓝作为强调色。

约束：所有文字必须是准确的简体中文或指定英文缩写；不加入未指定的品牌 Logo；无水印；避免乱码、伪中文、密集小字、3D 卡通人物、拟人机器人和复杂代码截图。

## 定点修正

仅修正底部中央紫色标签文字为“幂等注入”，保持其他文字、架构模块、图标、布局、颜色和发光效果不变。
